## Read the following conversation and answer Questions 1–4.

Three students, Aki, Ken, and Yuna, are preparing a small computer system for an exhibition at their university.

* * *

**Aki:** We need a computer for the interactive display. I think using a Raspberry Pi would be enough for this project. It is much cheaper than using a laptop, and we don't need a large screen or a keyboard.

**Ken:** I agree. The program only needs to receive information from the sensor and display some images. We don't need much processing power, so buying a laptop would be a waste of money.

**Yuna:** Then let's use the Pi we already have in the laboratory. We can spend the money we save on other parts of the system.

**Aki:** Good idea. Let me check which model it is. Hmm... it's a Raspberry Pi 4, so it should be powerful enough for what we are planning to do.

**Ken:** Great. Then we can decide on the rest of the hardware.

* * *

**Yuna:** What about storage? We need somewhere to keep the operating system and the images used by the display. We could buy a new SSD, but that would add another expense.

**Ken:** Wait. We have a few SSDs left in the laboratory. We should use one of those instead of buying a new one.

**Aki:** Let me see... your storage is... from SUN-TECH?! We shouldn't use it.

**Ken:** Is there something wrong with it? It still works, doesn't it?

**Aki:** It may work, but I'd rather not use it for this system. We have another SSD here. Oh, an M-Series is available. Let's replace it with that one.

**Yuna:** That seems reasonable. If we already have a better-known SSD available, there is no reason to take the risk.

* * *

**Ken:** So, the main components are decided. But there is one more thing we need to think about. The Pi will be processing sensor data continuously during the exhibition, so it may get quite warm.

**Yuna:** We could just put it inside the case and leave it there. The exhibition room should be air-conditioned.

**Aki:** I'm not sure that's enough. The case doesn't have much room for airflow, and the system will be running for several hours at a time. We should prepare some kind of **thermal solution**.

**Yuna:** A thermal solution? What do you mean?

**Aki:** Something that can help remove heat, such as a heatsink or a small fan. We don't necessarily need to buy anything expensive.

**Ken:** Aki, I heard that your family runs an electronics store. Do you have any thermal solutions available?

**Aki:** We might. I'll ask my family whether we have a small fan or heatsink that would fit the Pi. If we can reuse one, we won't have to change our budget.
